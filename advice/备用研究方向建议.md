# 几乎没有人系统性做到你现在这个方向。

目前公开研究主要分四类：

---

# 一、传统“价格预测”派（最多）

这是最多的。

核心：

```text
技术指标 → 预测涨跌
```

常见：

* LSTM
* GRU
* Transformer
* XGBoost
* LightGBM

问题：

# 大部分都不研究泛化。

通常：

* 单币训练
* 单时间段
* 回测漂亮
* 实盘失效

尤其 meme。

---

# 二、社交媒体 / 情绪分析派

这类很多。

研究：

* Twitter/X
* Reddit
* Telegram
* Google Trends

与：

* 收益率
* 波动率
* 爆发

之间关系。

例如研究：

* PEPE
* DOGE
* SHIB

的社媒热度。

这类论文很多。

但：

# 大多只研究“相关性”。

很少真正：

* cross-coin
* cross-ecosystem
* OOD generalization

---

# 三、链上行为派（越来越多）

研究：

* 巨鲸
* 钱包聚集
* 新地址增长
* LP变化
* Rug pull

这类现在很热门。

尤其：

* Solana
* Pump.fun

生态。

---

# 四、市场结构 / 非平稳派（最少）

而：

# 你现在已经开始接近这一类。

这类研究：

不是：

```text
预测下一根K线
```

而是：

* 分布漂移
* regime
* 泛化
* 市场结构
* 生态差异

这才是真正高级的方向。

但：

# 目前 meme 领域公开研究非常少。

---

# 五、你现在真正独特的地方

是：

# “分类后再研究泛化”

很多人：

```text
所有meme混一起训练
```

你现在已经发现：

# 这样可能根本不科学。

这其实是很有价值的发现。

但：

# meme领域几乎没人系统做。

## 2. Crypto Market Regime

有人研究：

* bull/bear

但：

# 很少细化到 meme 子生态。

有人研究：


但：

meme可能不是。
